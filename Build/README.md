# Build/ — ejecutable del Hito 2

`VRCar-Hito2-Windows.zip` es la compilación de escritorio (Windows x64) del prototipo lo-fi.

- **Cómo ejecutarlo:** descomprimir y abrir `unity.exe` (ver el README de la raíz, sección *Ejecutar el prototipo*).
- **Escena incluida:** `Parking_Perpendicular` (estacionamiento perpendicular, caso de uso 2).
- **Compilado con:** Unity 6000.4.0f1, plataforma Windows, arquitectura Intel 64-bit, sin *Development Build*.
- **Fecha de compilación:** 13-oct-2026.
- **Controles:** teclado (W/S/A/D) o Meta Quest 3 conectado con Meta Quest Link (OpenXR).
- **No incluye** el `.apk` para Meta Quest 3 (pendiente: falta el módulo Android de Unity en el equipo de build).
